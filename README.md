### 👁️ Real-Time Object Detection & Tracking

A computer vision project focused on building a practical real-time pipeline for **object detection, multi-object tracking, trajectory analysis, and object counting**.

The project currently combines **YOLO + ByteTrack** and explores the underlying concepts behind modern detection and tracking systems, including:

* Bounding boxes and confidence scores
* IoU
* Non-Maximum Suppression (NMS)
* Class-aware NMS
* Video-based detection
* Multi-object tracking
* Track IDs
* Detection and processing performance

The project is being developed incrementally toward trajectory analysis, counting, evaluation, and robustness analysis.

**Tech:**
`Python` · `PyTorch` · `YOLO` · `OpenCV` · `ByteTrack` · `Jupyter` · `Google Colab`
